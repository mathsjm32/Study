# 에듀테크 경쟁사 유튜브 벤치마킹 파이프라인

193개 경쟁사의 유튜브 채널을 자동으로 찾아 수집하고, 영상 단위 지표를 채널 단위로
집계해 **"배울 점 / 부족한 점"을 근거와 함께** 엑셀 리포트로 산출합니다.

사람이 193개 채널의 영상을 전부 보는 대신, 기계가 지표를 만들고 LLM이 상·하위
영상의 패턴을 해석합니다. 사람이 할 일은 **채널 매칭 검수**와 **결론 판단**뿐입니다.

## 30초 체험 (API 키 불필요)

```bash
pip install -r requirements.txt
python -m ytbench demo
```

모의 데이터 193채널 / 1만 영상으로 전 과정이 돌고, 10개 시트짜리 엑셀이 생성됩니다.

## 파이프라인

```
companies.csv (회사명 193개)
      │
      ├─ resolve  ─ 회사명 → 채널 매칭 (신뢰도 점수 + 검수 플래그)
      ├─ collect  ─ 채널 메타 + 최근 영상 100개 (이어받기 지원)
      ├─ analyze  ─ 파생 지표 → 성공 패턴 역산 → 6축 벤치마크 스코어
      ├─ llm      ─ 채널별 배울 점 / 부족한 점 / 실행안 (근거 인용 강제)
      └─ report   ─ 엑셀 10시트
```

## 설계에서 중요한 결정 3가지

**1. 절대 조회수로 비교하지 않습니다.**
구독자 200만 채널이 20만 채널보다 조회수가 높은 건 정보가 아닙니다. 모든 지표를
193개 모집단 내 **백분위**로 변환하고, 효율성 축(구독자당 조회수)에 가장 큰 가중치
25%를 둡니다. 그래서 작지만 잘하는 채널이 상위에 올라옵니다.

**2. 제목 패턴을 통념이 아니라 데이터로 검증합니다.**
"제목에 숫자를 넣어라" 같은 규칙을 그대로 점수화하지 않습니다. 대신 수집된 전체
영상에서 각 패턴의 **리프트**(패턴 적용 영상의 채널내 상대조회수 중위 ÷ 미적용
중위)를 계산해, 에듀테크 업계에서 실제로 먹히는 패턴만 골라 채점합니다.
비교 기준을 '채널 내부 상대 조회수'로 둔 것은, 대형 채널이 많이 쓰는 패턴이
좋아 보이는 편향을 제거하기 위함입니다.

**3. LLM에게 근거 인용을 강제합니다.**
출력 스키마에서 모든 '배울 점'과 '부족한 점'에 `evidence` 필드를 필수로 두고,
시스템 프롬프트에서 데이터에 없는 사실(매출, 광고비, 조직 규모)의 추측을 금지합니다.
그래서 "콘텐츠 품질을 높여라" 같은 쓸 수 없는 조언 대신
"참여율 4.1%(업계 상위 12%), 제목 상위 6편이 성과인증형" 같은 문장이 나옵니다.

## 한계 (알고 쓰는 것이 중요)

- **한글 사명 ↔ 영문 채널명**은 문자열 유사도가 0이라 자동 매칭이 실패합니다.
  `08_매칭검수` 시트에서 걸러지므로 URL을 직접 넣어야 합니다.
- YouTube API는 **시청 시간·이탈률·노출 클릭률을 제공하지 않습니다.** 조회수와
  참여 지표만으로 추론하므로, "왜 안 봤는지"는 알 수 없습니다.
- 좋아요·댓글을 비공개로 둔 채널은 참여율이 공란입니다(0으로 채우면 왜곡되므로
  계산에서 제외).
- 스코어는 **수집된 경쟁사 집단 내 상대 위치**입니다. 유튜브 전체 기준 절대
  평가가 아닙니다.
