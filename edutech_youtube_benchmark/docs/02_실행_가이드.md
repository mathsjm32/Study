# 실행 가이드

## 설치

```bash
cd edutech_youtube_benchmark
pip install -r requirements.txt
```

## 0단계 — 키 없이 먼저 구조 확인 (권장 시작점)

```bash
python -m ytbench demo
```

모의 데이터 193채널 / 약 1만 영상을 만들어 분석·리포트까지 전 과정을 실행합니다.
`output/에듀테크_경쟁사_유튜브_벤치마킹.xlsx` 를 열어 **어떤 시트에 무엇이 담기는지
먼저 확인**하고, 필요한 지표가 빠졌으면 이 시점에 말해주세요. 실데이터 수집 전에
고치는 게 훨씬 쉽습니다.

## 1단계 — 경쟁사 목록 확인

**이미 193개가 들어 있습니다** (`data/exhibitors_2026.csv`, 에듀테크 코리아 페어 전시기업).
그대로 쓰려면 이 파일을 `data/companies.csv` 로 복사하면 됩니다.

```bash
cp data/exhibitors_2026.csv data/companies.csv
```

다른 목록을 쓰려면 `data/companies_template.csv` 를 복사해 채웁니다.

| 컬럼 | 필수 | 설명 |
|---|---|---|
| `company_name` | ✅ | 회사명. 이것만 있어도 동작합니다 |
| `channel_url` | | 아는 채널 URL. **채울수록 쿼터가 100배 절약됩니다** |
| `category` | | 세그먼트(입시/어학/코딩 등). 세그먼트별 비교 시트가 활성화됩니다 |
| `aliases` | | 같은 회사의 다른 표기(영문명·제품명). `\|` 로 구분. **쿼터 추가 소모 없이 매칭률을 올립니다** |
| `note` | | 자유 메모 |

컬럼명은 한글(`회사명`, `채널url`, `분류`)도 인식합니다. 엑셀에서 저장할 때는
**CSV UTF-8** 형식을 선택하세요.

## 2단계 — 사전 추정

```bash
python -m ytbench estimate
```

쿼터가 며칠 걸릴지, LLM 비용이 얼마인지 **API를 한 번도 호출하지 않고** 계산합니다.
여기서 "3일 필요"라고 나오면 1단계로 돌아가 `channel_url`을 채우는 편이 빠릅니다.

## 3단계 — 채널 매칭

```bash
python -m ytbench resolve
```

회사명으로 채널을 찾아 `data/processed/channels_resolved.csv` 에 신뢰도와 함께 기록합니다.

- 신뢰도 **0.70 이상** → 자동 확정
- **0.45 ~ 0.70** → `needs_review=True` (검수 권장)
- **0.45 미만** 또는 검색결과 없음 → 실패로 기록

**검수는 꼭 하세요.** 오매칭 1건은 그 채널의 모든 수치를 오염시킵니다.
리포트 `08_매칭검수` 시트에서 대상을 확인하고, 맞는 채널 URL을 `companies.csv`에
채워 `resolve`를 다시 돌리면 해당 건만 갱신됩니다.

> 한글 사명과 영문 채널명이 다른 경우(예: 뤼이드 ↔ Riiid)는 문자열 유사도가 0이라
> 자동 매칭이 실패합니다. 이 유형은 URL을 직접 넣는 것이 유일한 해결책입니다.

## 4단계 — 영상 수집

```bash
python -m ytbench collect
# 범위 조정
python -m ytbench collect --max-videos 200 --lookback-days 730
```

채널당 최근 100개(기본), 1년 이내 업로드를 수집합니다. 중단되어도 다시 실행하면
**이미 수집한 채널은 건너뜁니다.**

## 5단계 — 지표·스코어

```bash
python -m ytbench analyze
```

API 호출이 없어 몇 초면 끝나고, 몇 번이든 다시 돌려도 됩니다. 산출물:

- `video_features.csv` — 영상별 파생 지표
- `channel_metrics.csv` — 채널별 집계 지표
- `channel_scores.csv` — 6축 점수 + 순위 + 등급
- `pattern_lift.csv` — 제목·포맷 패턴별 성과 리프트

## 6단계 — LLM 정성 분석

```bash
export ANTHROPIC_API_KEY="sk-ant-..."

# 비용 먼저 확인
python -m ytbench estimate

# 상위 20개만 시험 실행 (약 $0.35)
python -m ytbench llm --max-channels 20 --sync

# 193개 전체 (Batch API, 약 $3.3, 보통 1시간 내)
python -m ytbench llm

# 썸네일 이미지까지 분석 (약 $4.5)
python -m ytbench llm --thumbnails
```

| 옵션 | 효과 |
|---|---|
| `--sync` | Batch 대기 없이 즉시 결과. 비용 2배 |
| `--max-channels N` | 상위 N개만 분석. 시험 실행용 |
| `--thumbnails` | 상위 영상 썸네일을 이미지로 함께 분석 |
| `--effort low/high/max` | 추론 강도. 기본 `medium` |

부분 실행 결과는 누적 병합되므로, 상위 20개를 먼저 보고 만족스러우면 전체를
돌리는 방식이 안전합니다.

## 7단계 — 엑셀 리포트

```bash
python -m ytbench report
python -m ytbench report --out output/2026Q3_벤치마킹.xlsx
```

## 일괄 실행

```bash
python -m ytbench all                # 전체
python -m ytbench all --skip-llm     # LLM 제외
```

## 정기 갱신 운영

채널 매칭이 한 번 끝나면 이후 갱신은 쿼터 800 units 정도라 매주 돌릴 수 있습니다.

```bash
# 주간 갱신 (매칭 생략, 수집~리포트만)
python -m ytbench collect --no-resume && python -m ytbench analyze && python -m ytbench report
```

`--no-resume`을 주는 이유: 기본 이어받기는 '이미 수집된 채널'을 건너뛰므로,
최신 영상을 새로 받으려면 이어받기를 껴야 합니다. 원본은 `data/raw/*.jsonl`에
누적 append되고 파싱 단계에서 `video_id` 기준 최신값만 남으므로, 조회수가
갱신된 시계열을 나중에 분석하고 싶으면 이 JSONL을 보관하세요.

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| `수집된 영상이 없습니다` | `collect` 미실행, 또는 `lookback_days` 안에 업로드가 없음 |
| 03_LLM인사이트 시트가 안내문만 | `ANTHROPIC_API_KEY` 미설정 또는 `llm` 미실행 |
| 특정 채널 지표가 전부 공란 | 영상 0개 채널(정상) 또는 매칭 실패 |
| 참여율이 공란 | 좋아요·댓글을 비공개로 설정한 채널 (0과 구분해 제외 처리) |
| 07_세그먼트비교가 비어 있음 | `companies.csv`의 `category` 컬럼이 비어 있음 |
| 모멘텀이 공란 | 최근 180일 내 표본이 부족한 채널 |
