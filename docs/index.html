shortform-kpi

숏폼 콘텐츠(Shorts · Reels) 성과 지표 자동 수집 및 분석 도구

이 도구는 무엇인가요

운영자가 직접 소유하거나 관리 권한을 가진 소셜 채널에 업로드한 숏폼 콘텐츠의 성과 지표를 주기적으로 자동 수집하여, 콘텐츠별 성과를 비교·분석할 수 있게 하는 개인용 분석 도구입니다. 수작업으로 각 플랫폼의 대시보드를 열어 수치를 옮겨 적던 과정을 자동화하는 것이 목적입니다.

주요 기능

  • YouTube Shorts · Instagram Reels · Facebook Reels 성과 지표 자동 수집
  • 조회수 · 좋아요 · 댓글 · 공유 · 저장 · 시청 시간 등의 시계열 추적
  • 플랫폼별 지표 정의 차이를 보정한 비율 지표(참여율 · 저장률 · 공유율) 산출
  • 수집 데이터를 기반으로 한 성과 대시보드 제공

Google 사용자 데이터를 어떻게 사용하나요

이 도구는 사용자가 명시적으로 권한을 부여한 본인의 YouTube 채널에 대해 읽기 전용 권한(youtube.readonly, yt-analytics.readonly)만 요청합니다. 영상의 업로드 · 수정 · 삭제 권한은 요청하지 않으며, 수집한 데이터는 운영자 본인의 비공개 데이터베이스에만 저장되고 외부에 제공되지 않습니다.

자세한 내용은 개인정보처리방침을 참고해 주세요.

배포 형태

이 도구는 공개 서비스가 아니라 운영자 본인의 로컬 환경에서 실행되는 자체 분석 스크립트입니다. 소스 코드는 GitHub 저장소에서 확인할 수 있습니다.
