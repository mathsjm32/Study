개인정보처리방침

최종 수정일: 2026년 9월 16일

본 방침은 숏폼 콘텐츠 성과 분석 도구 shortform-kpi(이하 "본 도구")가 Google 사용자 데이터를 어떻게 수집 · 이용 · 저장 · 공유하는지 설명합니다.

1. 본 도구의 성격

본 도구는 일반에 제공되는 서비스가 아니라, 운영자가 본인이 소유하거나 관리 권한을 보유한 소셜 채널의 콘텐츠 성과를 분석하기 위해 운영자 본인의 환경에서 실행하는 개인용 분석 스크립트입니다. 회원 가입 절차가 없으며 불특정 다수의 이용자를 대상으로 하지 않습니다.

2. 요청하는 권한 범위

범위용도
youtube.readonly 채널 및 영상의 기본 정보(제목, 게시일, 길이 등) 조회
yt-analytics.readonly 영상별 성과 지표(조회수, 좋아요, 댓글, 공유, 재생목록 추가, 시청 시간) 조회

두 범위 모두 읽기 전용입니다. 본 도구는 영상의 업로드 · 수정 · 삭제, 댓글 작성, 채널 설정 변경 등 어떠한 쓰기 권한도 요청하지 않으며 수행할 수 없습니다.

3. 수집하는 데이터

  • 채널 식별자 및 채널명
  • 영상 식별자, 제목, 게시 일시, 영상 길이
  • 영상별 성과 지표: 조회수, 좋아요 수, 댓글 수, 공유 수, 재생목록 추가 수, 추정 시청 시간, 평균 시청 지속률, 구독자 증감

시청자 개개인을 식별할 수 있는 정보는 수집하지 않습니다. Google이 제공하는 지표는 모두 집계된 형태이며, 본 도구는 그 이상의 개인 정보에 접근하지 않습니다.

4. 데이터의 이용 목적

수집한 데이터는 오직 콘텐츠 성과 분석 목적으로만 이용됩니다. 구체적으로 콘텐츠별 성과 비교, 시계열 추이 확인, 참여율 · 저장률 · 공유율 등 파생 지표 산출에 사용됩니다. 광고 타게팅, 인물 프로파일링, 머신러닝 모델의 외부 판매 등 다른 목적으로는 이용하지 않습니다.

5. 데이터의 저장

수집한 데이터는 운영자가 관리하는 비공개 Google BigQuery 데이터셋에 저장됩니다. 해당 데이터셋은 운영자 계정에만 접근 권한이 부여되어 있으며 공개되지 않습니다. 인증에 사용되는 토큰은 운영자의 로컬 환경에만 보관되며, 버전 관리 시스템이나 공개 저장소에 포함되지 않습니다.

6. 데이터의 공유

본 도구는 수집한 데이터를 제3자에게 판매 · 양도 · 공개하지 않습니다. 데이터를 외부 서비스로 전송하지 않으며, Google API로부터 받은 데이터는 운영자의 저장소를 벗어나지 않습니다.

7. 보관 기간 및 삭제

데이터는 분석 목적이 유지되는 동안 보관하며, 목적이 종료되면 데이터셋 전체를 삭제합니다. 채널 소유자가 삭제를 요청하는 경우 해당 채널의 데이터를 즉시 삭제합니다.

8. 접근 권한 철회 방법

권한을 부여한 Google 계정에서 언제든지 접근을 철회할 수 있습니다. Google 계정 > 보안 > 타사 앱 및 서비스 에서 본 도구를 선택해 액세스를 삭제하면 즉시 데이터 수집이 중단됩니다.

9. Google API 서비스 사용자 데이터 정책 준수

본 도구의 Google API로부터 수신한 정보의 이용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책 (제한적 사용 요건 포함)을 준수합니다.
